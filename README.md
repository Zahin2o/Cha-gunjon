# দোকান হিসাব — GitHub Pages

বাংলা, মোবাইল-ফ্রেন্ডলি দোকানের বিল অ্যাপ। কোনো build command লাগে না।

## GitHub Pages-এ প্রকাশ
1. GitHub-এ sign in করুন এবং **New repository** চাপুন।
2. Repository name দিন `dokan-hisab` এবং Public নির্বাচন করে Create repository করুন।
3. **Add file → Upload files** নির্বাচন করুন।
4. এই ZIP-এর ভেতরের `index.html`, `style.css`, `app.js` ও `README.md` ফাইলগুলো আপলোড করুন (ZIP ফাইলটি নিজে আপলোড করবেন না)।
5. **Commit changes** চাপুন।
6. Repository-এর **Settings → Pages** খুলুন।
7. **Build and deployment**-এ Source: **Deploy from a branch**, Branch: **main**, Folder: **/(root)** নির্বাচন করে Save করুন।
8. কিছুক্ষণ পরে Pages পেজে প্রদর্শিত `https://YOUR-USERNAME.github.io/dokan-hisab/` লিংক খুলুন।

## প্রথমবার ব্যবহার
- **পণ্য ও দাম** ট্যাবে যান। উদাহরণ পণ্যের নাম/দাম আপনার দোকানের প্রকৃত তথ্য দিয়ে Edit করুন; অপ্রয়োজনীয় পণ্য Delete করুন।
- নতুন সিগারেটের প্রতিটি ব্র্যান্ড আলাদা পণ্য হিসেবে যোগ করুন। শলাকা ও প্যাকেট আলাদা রাখতে চাইলে আলাদা পণ্য ও দাম দিন।
- বিক্রির সময় **নতুন কাস্টমার** → টোকেন নির্বাচন → পণ্যে চাপ → **টাকা নিয়েছি · বিল সম্পন্ন**।
- প্রতিদিন **ব্যাকআপ নিন** চাপ দিয়ে JSON ফাইল নিরাপদে রাখুন। অন্য ডিভাইসে এই ব্যাকআপ আমদানি করা যাবে, তবে ডিভাইস দুটির ডেটা live sync হবে না।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- ডেটা browser Local Storage-এ থাকে। একই ব্রাউজার/ডিভাইসে সাধারণত থাকবে; browser data clear, profile change বা device change হলে হারাতে পারে।
- Live link কম্পিউটার ও মোবাইলে খোলা যাবে, কিন্তু Local Storage আলাদা হওয়ায় হিসাব আলাদা থাকবে।
- এটি স্টক/ক্রয়/লাভ-ক্ষতি হিসাব করে না; শুধু বিক্রির বিল ও সম্পন্ন বিলের ইতিহাস রাখে।
- দাম ও পণ্যের তালিকা উদাহরণ হিসেবে দেওয়া। চালুর আগে নিজের দোকানের সঠিক দাম বসান।
